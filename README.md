# Аквадом — водоподготовка для частного дома

Самостоятельный адаптивный лендинг на HTML/CSS/JavaScript без сторонних JS-зависимостей. Готовые файлы находятся в `dist/`.

## Запуск

Требуется Node.js 22 или новее. Установка пакетов не нужна.

```sh
npm run dev
npm run check
npm run build
```

Локальный адрес: http://localhost:4173. Для своего хостинга загрузите содержимое `dist/` с сохранением структуры. Нужен HTTPS и разрешение на загрузку ресурсов CRM с `crm-aquadom.ru` и доменов, используемых самой формой. Собственный backend не используется.

## CRM-форма

`dist/app.js` лениво подключает предоставленную форму `inline/3/jjh64m` в единственный нативный `<dialog>`. Идентификатор и URL загрузчика сохранены. Загрузчик запрашивается один раз за посещение; закрытие и повторное открытие не пересоздают форму. При ошибке сети или отсутствии отрисованной формы в течение 15 секунд доступны телефон и email. Если форма появится позже, она заменит fallback.

Название выбранного направления отображается над формой. Оно **не передаётся в CRM**, пока не подтверждены поддерживаемый API и поле формы. Не заявляйте обратное. Поля, согласие, обработка отправки, назначения ответственных и результат отправки настраиваются в Битрикс24.

Событие `aquadom:form-open` содержит только направление и место открытия; можно подключить согласованную аналитику. Открытие формы не считается успешной заявкой. Данные посетителей и отдельный трекер сайт не собирает.

## Фактический контент и материалы

Цены на шесть направлений взяты из предоставленного документа, это цены только на оборудование. Монтаж, доставка, состав системы и актуальность начальной цены требуют подтверждения перед рекламным запуском. Производительность, гарантии и сроки не придуманы.

Контакты, юридические сведения, адрес и ссылка на политику взяты с aquadom.info. Оригинальный логотип, фотографии работ, модели и кейсы не предоставлены. Вместо них используются текстовое название компании, технические SVG-схемы и подписанное иллюстративное изображение оборудования. Раздел вымышленных кейсов отсутствует.

`dist/assets/water-system.png` создан встроенным imagegen. Это не фотография выполненного объекта. Исходный запрос: photorealistic architectural product photograph, vertical 4:5, two pale gray fiberglass pressure filter vessels with black automatic control heads, white salt brine tank, blue prefilter housing, neat white pipes, cool daylight, unbranded modern utility room, no text, no logos, no people; illustrative assembly, not a specific installation. Используется в первом экране и блоке компании. Перед финальной рекламной публикацией желательно заменить настоящими фотографиями компании.

Схемы `dist/assets/{uv,clarification,sorption,iron,softening,complex}.svg` нарисованы в коде и показывают принцип, а не конкретный товар. Генератор: `scripts/create-diagrams.mjs`.

Шрифт Manrope сохранён локально, лицензия — `dist/assets/Manrope-OFL.txt`.

## Перед публичным запуском

- Подтвердить цены, возможность монтажа и контакты ответственного за заявки.
- Проверить доступность предоставленного CRM-загрузчика на целевом домене и разрешённые домены в настройках формы.
- Выполнить согласованную тестовую отправку и подтвердить запись в Битрикс24. Реальные обращения в процессе разработки не отправлялись.
- Проверить применимость политики конфиденциальности к итоговому адресу и содержание согласия в CRM-форме.
- Заменить иллюстративные материалы при наличии фотографий, логотипа и кейсов.
