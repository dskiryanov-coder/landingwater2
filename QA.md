# Проверка лендинга

Проверено 5 ноября 2026 года, браузер Chromium через Playwright.

- 50 проверок в `tests/browser-check.js` прошли. Загрузчик CRM перехвачен и заменён тестовой имитацией; никаких обращений в CRM не отправлено.
- Нет горизонтального переполнения при 320, 390, 768, 1024, 1440 и 1920 px.
- Все изображения и локальные шрифты загружаются. Один h1, шесть систем с предоставленными ценами.
- Для каждой из шести систем открывается один dialog с соответствующим заголовком. Загрузчик запрашивается один раз, повторное открытие сохраняет форму.
- Escape закрывает окно и возвращает фокус на кнопку. Мобильная панель не перекрывает открытый dialog.
- Проверены общий подбор, выбор/сброс проблемы, мобильное меню и FAQ.
- При сетевой ошибке показываются контакты, при отсутствии содержимого срабатывает таймаут 15 секунд. Форма, появившаяся позднее, убирает fallback.
- JavaScript-исключений в проверенных сценариях нет. `npm run check` и `npm run build` пройдены.
- Вручную просмотрены первый экран при 1440 и 390 px, каталог на широком экране.

Автоматический инспектор design-taste-frontend не запустился из-за CDP timeout на Page.enable. Его заменили браузерные проверки Playwright и просмотр скриншотов. Длинный согласованный заголовок первого экрана сохранён, несмотря на рекомендацию навыка ограничивать его двумя строками.

Предоставленный загрузчик crm-aquadom.ru не ответил в пределах сетевого таймаута среды разработки. Настоящие поля формы, согласия и поступление обращения в Битрикс24 не проверены. Перед рекламным запуском обязательна проверка на целевом домене.
